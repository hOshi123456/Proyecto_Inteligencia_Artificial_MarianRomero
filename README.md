# Proyecto_Inteligencia_Artificial_MarianRomero

Este proyecto corresponde a la materia Inteligencia Artificial.

Se trabaja con el dataset Sample Sales Data de Kaggle en formato CSV, realizando limpieza, normalización de datos y conexión con la API de Mistral AI para responder consultas sobre el dataset.

## Tecnologías utilizadas

- Python
- Google Colab
- Pandas
- Requests
- Mistral AI API
- GitHub

## Objetivo del proyecto

El objetivo es aplicar conceptos de inteligencia artificial y análisis de datos sobre un dataset de ventas, preparando los datos mediante limpieza y normalización, y utilizando un modelo de Mistral para generar respuestas basadas en la información procesada.
